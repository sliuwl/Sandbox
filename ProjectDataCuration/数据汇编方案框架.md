## 一、科学数据概述

### 1.1 项目背景（含关键科学问题）

| 项目信息 | 内容 |
|---------|------|
| 项目名称 | （待填写：项目全称/编号） |
| 研究对象 | HfO₂ / Hf₀.₅Zr₀.₅O₂（HZO）基铁电薄膜及铁电存储器 |
| 核心科学问题 | 1. 电荷补偿式共掺杂下给体-受体缺陷复合物对铁电相稳定性、多晶相变能垒、极化翻转能垒的影响机制；<br>2. HZO基超薄外延薄膜在硅基/金属氧化物衬底上的可控生长与界面调控；<br>3. 多层次结构（缺陷、畴结构、晶界等）在外场下的动力学行为与宏观铁电性能的关联；<br>4. 面向高密度存储的HZO基铁电存储器器件集成方案。 |
| 技术路线 | “模拟-制备-表征-器件”一体化：第一性原理计算 → 经典力场开发 → 大尺度分子动力学 → 薄膜外延制备 → 多尺度表征 → 机器学习优化 → 存储器芯片设计与测试。 |

| 维度 | 框架说明 |
|-----|---------|

| 数据类型 | 原始数据、分析数据、计算输入/输出、设计报告、测试报告、论文、专利、代码/脚本 |
| 主要格式 | `.txt`、`.csv`、`.xlsx`、`.dat`、`.out`、`.cif`、`.xsf`、`.vasp`、`.json`、`.pdf`、`.docx`、`.png`、`.jpg` 等 |
| 共享策略 | （待确定：例：完全共享，保护期 3 年；涉及器件工艺/专利申请部分可设置更长保护期） |

### 4.2 命名规范建议

- 数据项文件：`[数据集编号]-[数据项序号]-[简短描述]-[日期].[扩展名]`
  - 例：`2024YFBxxxxx-01-001-01-RHEED-HZO-STO-20240615.jpg`
- 论文/专利相关：保留原始投稿/申请编号，并在登记表中关联。

### 4.3 协作流程

1. 各子任务负责人根据本框架，填写《数据项登记表》（Excel 模板见第五节）。
2. 定期汇总至 `ProjectDataCuration/00_项目总体文档/数据项登记表.xlsx`。
3. 原始大文件可存放于项目服务器/云盘，登记表中记录相对路径或链接。
4. 论文/专利发表后，将相关数据归档至对应数据集，并更新共享状态。
