# HW2 — Worked Solutions

Worked solutions for Problem Set 2. The full statements, with figures, are also collected in `HW2_problems_EN.md`.

## Files

- HW2_answers_EN.md — complete English solutions.
- hw2_calculations.py — numerical integration and figure-generation code.
- numerical_results.json — computed values.
- fermat_ray.png / fermat_ray.svg — graded-index ray illustration.
- flight_path.png / flight_path.svg — the proposed flight path.
- images/optics.png — refraction diagram for Fermat's principle.
- images/fig6_10.jpg — Taylor Figure 6.10 (Problem 6.5).
- images/sphere.png — spherical-pendulum diagram.
- HW2_problems_EN.md — the same problems gathered as a stand-alone problem set.

Keep the images beside the Markdown file to display them. Running the optional Python script requires NumPy, SciPy, and Matplotlib.
