Bird’s-Eye View of Classical Mechanics

Classical mechanics provides different but equivalent ways to describe motion. Each formulation uses a different set of ideas, but they all lead to the same goal: finding the equations of motion.

Classical Mechanics

Three complementary formulations of motion

N

Newtonian Mechanics

Physical space

Main idea

Motion is described directly using forces, mass, and acceleration.

\[ \frac{d\vec{p}}{dt}=\vec{F} \]

This is the most familiar formulation. It is especially useful when the forces acting on the object are easy to identify.

L

Lagrangian Mechanics

Configuration space

Main idea

Motion is determined by the principle of stationary action. Instead of starting from forces, we usually start from energies.

\[ \frac{\partial L}{\partial q} - \frac{d}{dt} \left( \frac{\partial L}{\partial \dot q} \right) =0 \]

This formulation is powerful for systems with constraints, generalized coordinates, and symmetries.

H

Hamiltonian Mechanics

Phase space

Main idea

Motion is described as a flow in phase space, whose coordinates are position \(q\) and momentum \(p\).

\[ \frac{dq}{dt}=\frac{\partial H}{\partial p}, \qquad \frac{dp}{dt}=-\frac{\partial H}{\partial q} \]

This formulation connects naturally to statistical mechanics, quantum mechanics, and phase-space geometry.

Connection: Lagrangian and Hamiltonian mechanics are related by a Legendre transform, which changes the description from velocities \(\dot q\) to momenta \(p\).

Equations of Motion

All three formulations are different languages for describing the same physical motion.
